## Architecture & engineering

BandBinder brings product design, application engineering, cloud architecture, infrastructure as code, and automated delivery into one commercial product.

| Discipline                    | Current focus                                                                                           |
| ----------------------------- | ------------------------------------------------------------------------------------------------------- |
| **Application architecture**  | Offline-first Flutter/Dart across desktop and mobile, native platform integration, local data ownership |
| **Cloud architecture**        | GCP, Firebase, Azure, secure synchronization, operational reliability                                   |
| **Infrastructure & delivery** | Terraform, GitHub Actions, release automation, multi-platform pipelines                                 |
| **Product engineering**       | Turning real rehearsal and stage workflows into compact, dependable software                            |

Core tools: `Flutter` · `Dart` · `GCP` · `Firebase` · `Terraform` · `GitHub Actions` · `Python` · `PowerShell` · `.NET` · `SQL`

## Open source

I contribute code fixes, bug reports, documentation, and artwork to the open-source tools and communities I work with. My contributions span Flutter and Firebase, Windows WebView integration, Azure and Salesforce tooling, Docker, VS Code extensions, PowerShell package management, and ChordPro.

## How I work

I favor systems that are observable, automatable, portable, and resilient when their dependencies are not. Product decisions and architecture belong in the same conversation: the best technical design is the one that makes the product more dependable for the people using it.
